# Application File Management

## When to activate

Use when locating, naming or writing application deliverables.

## Procedure

1. Discover existing company/job directory.
2. Follow naming conventions for analysis, resume, letter and review files.
3. Check for existing versions before overwriting.
4. Write only to authorized application paths using approved tools.
5. Keep source records read-only.
6. Verify final paths and report them.

## Expected output

A clean directory inventory and verified paths.

## Domain-specific caution

Do not overwrite the candidate profile or unrelated applications.

## Standing safeguards

- Follow the invoking agent's AGENTS.md and actual tool/filesystem permissions. This skill does not grant new powers.
- Respect human-in-the-loop approval for all configured gated tools. For authoritative profile writes, obtain explicit candidate approval independently of tool approval.
- Preserve stable EXP-, PROJECT-, ACC-, SKILL-, EDU-, CERT-, EVID- and FUP- identifiers and link statements to the relevant records.
- Do not invent jobs, qualifications, scope, technology usage, quantifiable results, evidence or completion status.
- Open FUP records do not by themselves block producing an otherwise supported resume or cover letter.

## Scope

Intended agent group: **Application Development Agent**. For other agents, use only if their AGENTS.md explicitly permits the operation; route disallowed work to the owner.
